# DB Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Drizzle ORM database layer with PGLite (local) and PostgreSQL (production) support — schema definitions for sessions, session entries, compaction archives, and file snapshots, plus a client factory and migration runner.

**Architecture:** Drizzle ORM provides type-safe PostgreSQL schema definitions. PGLite runs a full WASM Postgres in-process (no server needed) for local development. Migration SQL files are generated via `drizzle-kit generate` and applied at runtime via `drizzle-orm/pglite/migrator`. The DB layer exposes a `createDB()` factory that returns a unified `{ db, client }` handle regardless of driver.

**Tech Stack:** `@electric-sql/pglite` (WASM Postgres), `drizzle-orm` (ORM + PGLite adapter), `drizzle-kit` (migration generation), `pg` + `drizzle-orm/node-postgres` (production PostgreSQL driver).

```typescript
import { sql } from 'drizzle-orm'
import {
  index,
  integer,
  jsonb,
  pgTable,
  text,
  timestamp,
  uniqueIndex,
  uuid,
} from 'drizzle-orm/pg-core'

/**
 * Sessions table — conversation sessions with branching support.
 * Root sessions have parentId = null. Forked sessions reference their parent.
 */
export const sessions = pgTable(
  'sessions',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    title: text('title').notNull(),
    parentId: uuid('parent_id').references((): ReturnType<typeof pgTable> => sessions.id),
    branchPoint: integer('branch_point'),
    metadata: jsonb('metadata').notNull().default({}),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index('idx_sessions_parent').on(table.parentId)],
)

/**
 * Session entries table — unified storage for all session content types.
 * The `tag` field discriminates: 'message' | 'tool_call' | 'tool_result' |
 * 'compaction' | 'squash' | 'branch_summary' | 'steering' | 'file_snapshot'.
 */
export const sessionEntries = pgTable(
  'session_entries',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    sessionId: uuid('session_id')
      .notNull()
      .references(() => sessions.id, { onDelete: 'cascade' }),
    tag: text('tag').notNull(),
    role: text('role'),
    content: jsonb('content').notNull(),
    toolName: text('tool_name'),
    tokenCount: integer('token_count').default(0),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [index('idx_entries_session').on(table.sessionId, table.createdAt)],
)

/**
 * Compaction archives — stores original entries that were compacted/squashed.
 * Searchable via full-text search on `searchableText`.
 */
export const compactionArchives = pgTable(
  'compaction_archives',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    sessionId: uuid('session_id')
      .notNull()
      .references(() => sessions.id, { onDelete: 'cascade' }),
    compactionId: uuid('compaction_id').notNull(),
    archiveType: text('archive_type').notNull(),
    originalEntries: jsonb('original_entries').notNull(),
    fileSnapshots: jsonb('file_snapshots').default([]),
    summary: text('summary').notNull(),
    tokenCount: integer('token_count'),
    searchableText: text('searchable_text'),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [
    index('idx_archives_session').on(table.sessionId),
    // Full-text search index (GIN) for archive content search
    // Using raw SQL because Drizzle doesn't have a first-class GIN tsvector builder
    sql`CREATE INDEX IF NOT EXISTS "idx_archives_search" ON "compaction_archives" USING gin(to_tsvector('english', coalesce(${table.searchableText}, '')))`,
  ],
)

/**
 * File snapshots — caches hot file content to avoid repeated read tool calls.
 * Versioned per (session_id, file_path).
 */
export const fileSnapshots = pgTable(
  'file_snapshots',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    sessionId: uuid('session_id')
      .notNull()
      .references(() => sessions.id, { onDelete: 'cascade' }),
    entryId: uuid('entry_id'),
    filePath: text('file_path').notNull(),
    content: text('content').notNull(),
    contentHash: text('content_hash').notNull(),
    tokenCount: integer('token_count').default(0),
    version: integer('version').default(1),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (table) => [
    index('idx_snapshots_session_path').on(table.sessionId, table.filePath),
    uniqueIndex('idx_snapshots_latest').on(table.sessionId, table.filePath, table.version),
  ],
)

/** Type exports for insert/select operations. */
export type SessionRow = typeof sessions.$inferSelect
export type SessionInsert = typeof sessions.$inferInsert
export type SessionEntryRow = typeof sessionEntries.$inferSelect
export type SessionEntryInsert = typeof sessionEntries.$inferInsert
export type CompactionArchiveRow = typeof compactionArchives.$inferSelect
export type CompactionArchiveInsert = typeof compactionArchives.$inferInsert
export type FileSnapshotRow = typeof fileSnapshots.$inferSelect
export type FileSnapshotInsert = typeof fileSnapshots.$inferInsert
```

Create `src/db/client.ts`:

```typescript
import { drizzle } from 'drizzle-orm/pglite'
import { drizzle as drizzlePg } from 'drizzle-orm/node-postgres'
import { Pool } from 'pg'
import * as schema from './schema.js'
import type { DBConfig } from './types.js'

/**
 * Unified database handle.
 * `db` is the Drizzle ORM instance with schema bound.
 * `client` is the underlying driver client (PGlite or Pool).
 * `close()` cleans up the connection.
 */
type DB = {
  db: ReturnType<typeof drizzle<typeof schema>>
  close(): Promise<void>
}

/**
 * Create a database connection.
 *
 * - PGLite mode: in-process WASM Postgres, no server needed.
 *   Pass `dataDir` for persistent storage, omit for in-memory (tests).
 * - PostgreSQL mode: connects to a real PG server via connection string.
 */
async function createDB(config: DBConfig): Promise<DB> {
  if (config.driver === 'pglite') {
    const dataDir = config.dataDir ?? ':memory:'
    const db = drizzle({ schema, connection: dataDir === ':memory:' ? undefined : { dataDir } })
    return {
      db,
      async close() {
        // PGLite manages its own lifecycle via the drizzle connection
      },
    }
  }

  // PostgreSQL mode
  const pool = new Pool({ connectionString: config.connectionString })
  const db = drizzlePg(pool, { schema })
  return {
    db,
    async close() {
      await pool.end()
    },
  }
}

export type { DB }
export { createDB }
```

> **Note on PGLite in-memory:** `drizzle()` with no `connection` argument creates an in-memory PGlite instance. This is ideal for testing. For persistence, pass `{ connection: { dataDir: 'path' } }`.

Create `src/db/migrate.ts`:

```typescript
import { resolve } from 'node:path'
import { fileURLToPath } from 'node:url'
import { migrate as drizzleMigrate } from 'drizzle-orm/pglite/migrator'
import type { DB } from './client.js'

/**
 * Run all pending database migrations.
 * Migration SQL files live in `drizzle/` at the project root.
 *
 * Must be called after `createDB()` and before any queries.
 */
async function migrateDB(handle: DB): Promise<void> {
  // Resolve migrations folder relative to this module.
  // In dev: src/db/migrate.ts → ../../drizzle/
  // In dist: dist/db/migrate.js → ../../drizzle/ (if drizzle/ is copied)
  const currentDir = fileURLToPath(new URL('.', import.meta.url))
  const migrationsFolder = resolve(currentDir, '..', '..', 'drizzle')

  await drizzleMigrate(handle.db, { migrationsFolder })
}

export { migrateDB }
```

### 4. Architecture Risk Assessment

**PGLite WASM in tests:** PGLite loads a WASM binary at runtime. In Node.js 22+, this should work out of the box. If WASM loading fails, the integration tests will error — this is a known risk that the tests will surface early.

**Self-referential FK:** `sessions.parentId` references `sessions.id`. This is handled via Drizzle's function reference `(): ReturnType<typeof pgTable> => sessions.id`. If this causes type issues, an alternative is to drop the FK constraint and enforce referential integrity at the application layer.

**Migration folder resolution:** `migrateDB` resolves the `drizzle/` folder relative to the module file. In development (`src/db/migrate.ts`), this resolves to `../../drizzle/`. In production (`dist/db/migrate.js`), the build must copy or symlink `drizzle/` to the appropriate location. This is a build-config concern, not a runtime concern — flagged for the CLI/Server plan.
